# 页集 · HTML 资料库

把 AI 生成的本地 HTML 放在一个入口里，搜索后直接打开。适用于 macOS，需要 Python 3.9 或更高版本，运行时仅使用 Python 标准库，无需安装第三方依赖。

## 开始使用

1. 双击 **开始使用.command**，启动后台收录并打开作品库。重复双击会复用正在运行的作品库。
2. 在浏览器按 **⌘D** 收藏入口：<http://127.0.0.1:18765>。
3. 默认每 **10 秒**收录 `~/Documents/Codex` 下新增或更新的 HTML；点击页面上的 **添加文件夹**，在 Mac 弹出的文件夹窗口中选择其他收录目录，无需填写路径。

默认跳过 `work`、`node_modules`、`templates`、`scripts` 等中间产物及依赖目录，减少搜索干扰。收录所需时间取决于目录大小。

关闭网页或启动时的终端后，后台会继续每 10 秒收录。**重启 Mac 或退出登录后，需要再次双击开始使用。** 电脑关闭或休眠时无法扫描，休眠恢复后继续。入口仅在这台电脑使用。

## 文件与数据

- 收录不会搬动或删除原始 HTML；原文件移动或删除后，旧入口可能失效。
- 目录配置和收录信息保存在本文件夹的 `.data` 中；服务只监听本机地址。
- 打开的原网页可能加载在线字体、脚本、图片或其他远端资源，是否需要网络由原网页决定。
- 运行中请保持整个 `html-library` 文件夹位置不变。

## 状态与排查

双击 **停止资料库.command** 可停止普通后台收录，保留数据和原文件；再次双击开始使用即可恢复。

在本文件夹打开终端可检查状态：

```sh
python3 manage.py status
```

界面端口为 `18765`，HTML 内容端口为 `18766`。启动失败时，确认两个端口未被其他程序占用，并查看 `.data/server.stderr.log`。

自启配置位于 `~/Library/LaunchAgents/local.html-library.plist`。管理脚本只会替换或移除属于本文件夹的配置。

## 可选的登录自启

默认采用双击启动。可选的登录自启需要 macOS 允许后台 Python 访问文稿目录；若权限受限，仍可使用双击启动方式。

如之后主动配置好了系统权限，可在作品库未运行时执行 `python3 manage.py install` 尝试登录自启。若启动失败，脚本会清理本次失败的自启配置，避免后台反复重试；脚本不会修改系统权限。

**停止自动启动.command** 仅用于停止可选的 LaunchAgent 并取消登录自启，不会停止通过“开始使用”直接启动的进程。源码、收录数据和原始 HTML 均保留。日常直接启动的进程会随退出登录或关机结束。

## 能力与限制

- 自动收录本地 HTML，支持标题、文件名、路径与静态正文关键词搜索。
- 网页分类、卡片/列表视图、收藏、最近打开、显示名称和 Finder 定位。
- macOS 原生文件夹选择窗口，选中后自动加入收录。
- 预览为静态内容，动画和脚本不会在预览中运行。纯 JavaScript 生成的正文无法通过静态索引搜索。
- 原网页依赖其他后端服务、运行时根路径 API 或复杂客户端路由时，需要其原应用运行环境。
- 本项目是本机工具，不是 GitHub Pages 网站。

## 源码与验证

`server.py` 提供扫描、搜索、SQLite 持久化和本地 HTTP 服务；`manage.py` 管理启动与停止；网页界面由 `index.html`、`app.js` 和 `styles.css` 组成。

运行集成检查：

```sh
python3 tests/integration_test.py
```

测试使用独立端口 18775/18776 和临时生成的文件，覆盖自动收录、中文搜索、持久化、资源加载与访问边界。测试不调用系统文件夹选择窗口；该窗口需要在 macOS 桌面会话中手动验证。
